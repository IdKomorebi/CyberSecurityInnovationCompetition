# 系统 V2

面向首次接触项目的评审者重做前端，沿用四个算例及已有计算接口。主线为：初始定级 → 发现推断风险 → 定位关键字段 → 调整等级 → 复核效果。旧版保留在 `../V1/`，公共算法位于 `../engine/`。

## 启动

在项目根目录运行：

```bash
python V2/scripts/serve.py 8782
```

浏览器打开 **http://127.0.0.1:8782/frontend/**。远程开发时转发 8782 端口。V1 可以同时使用 8780 端口，便于对比。

演示无需显卡、Node.js、外网或前端构建，图表库已随系统提供。建议使用近期的 Chrome、Edge 或 Firefox。

## 推荐查看顺序

1. **任务概览**：默认 IEEE 30 节点，查看“节点电价 + 机组出力 → 机组报价”的风险与调级后复核结果。
2. **数据资产与初始定级**：筛选候选共享字段、保护对象或修正过的初判。点击字段，在右侧查看对应依据。
3. **聚合推断风险**：先看保护对象 × 接收方的全字段推断矩阵，再选中一项，逐步添加字段并播放真实推断曲线。
4. **字段推断敏感度**：拖动 K，查看同一字段在不同背景信息下的增益；点击字段看见证组合。
5. **二次定级方案**：查看等级变化、调整依据、降回原级时重新成立的组合，以及强化学习的训练记录。
6. **效果复核与台账**：比较全部可见字段的推断效果，查看两种模型复测及共享范围变化；导出 CSV 台账或完整 JSON。

任务切换始终位于左侧上方。规则、推断参数、强化学习设置放在侧栏的“规则与算法设置”中。页面地址包含当前任务与页面，支持刷新和浏览器前进、后退。

## 数据口径

- 所有数字和曲线读取 `samples/*.json`，没有为展示生成预测曲线。
- R² 表示拟合优度，不是分类准确率。字段敏感度 M 表示最大增量贡献，不是泄露概率。
- 曲线来自缓存样本；多分量数据只画首个分量，组合 R² 则是所有分量的评估值。
- 初始定级中的“候选共享”是字段用途，不代表对所有接收方开放。推断路径按当前接收方的初始权限限制可选步骤。
- “已识别越线组合为零”和“全字段复核未越线”是两个指标。概览和最终结论保留所有全字段越线项，包括 PJM 的公开基底风险。
- 等级来自公开数据上的场景化设定，不是这些数据集的官方定级；推断判定线也不是标准规定的阈值。

## 导入与重跑

任务管理支持导入本系统导出的完整任务 JSON，校验数据结构后在当前页面载入，不覆盖内置文件。刷新后需要重新导入。原始表格上传和新任务训练尚未接入。

当 Python 环境有深度学习库，且当前版本的 `runtime/cache/` 存在该任务的缓存时，参数页可以调用现有 `/api/rerun` 接口重新计算。参数修改后须点“应用并重跑”，计算会更新 **V2 自己的**算例文件。没有计算环境或缓存时参数只读。此次前端更新没有重新训练算法。

重新生成算例：

```bash
python V2/scripts/build_samples.py ieee30 --gpu 0
```

## 浏览器巡检

仅巡检需要额外安装 Playwright 与 Chromium；运行演示不需要。

```bash
python -m pip install playwright
python -m playwright install chromium
python V2/scripts/shots.py --serve
```

可用 `--browser /path/to/chrome` 指定已有浏览器，`--port` 指定端口。巡检覆盖四个任务的十个页面、桌面与手机布局，以及搜索、权限限制、推断播放、K 交互、导出导入、历史导航和参数错误处理。参数提交测试使用模拟接口，不会启动真实 GPU 作业。
