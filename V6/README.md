# 系统 V6

在 V5 的基础上，按用户 10 月 14 日的第三轮意见改：单字段与聚合推断两页的颜色和读法，聚合推断页拆出“背景增益”，二次定级默认保护全部保护对象，并可在界面上另算“只保护某一项”。

## 启动

```bash
python V6/scripts/serve.py 8786 <显卡编号>     # 浏览器打开 http://127.0.0.1:8786/frontend/
```

## 页面

| 页面 | 内容 |
|---|---|
| 任务管理、总体概览、1 一次定级 | 同 V5 |
| 2 单字段推断风险 | 单字段判定线统一为 0.7（不分接收方），指标“单独可过线的字段”与表中结论都按它判断；左表每个字段的单独推断精度，颜色随精度由蓝到黄再到红逐渐加深，结论为“单独过线”或“单独不过线”；右侧为读数与推断曲线，图例可点选显示或隐藏曲线 |
| 3 聚合推断风险 | 顶部总览：每个字段的条由“单独作用（K = 0）”和红色斜纹的“背景增益”两段组成，右下角的小玻璃滑块调 K；左表按“单独作用 ＋ 背景增益 ＝ M”列出；右侧用竖向玻璃选择器单独切换 K（点选一行时默认为顶部的 K），把推断精度分成“只有背景、该字段单独作用、背景增益”三段 |
| 4 二次定级 | 顶部选择保护范围：默认“保护全部保护对象”（已计算）；每项保护对象另有“只保护这一项”的选项，未计算时为灰色，点击后在后台计算，算完可切换查看。下面依次为整套等级方案（效用、训练过程、构成）和字段调整明细 |
| 5 定级效果 | 同 V5；下方“换模型复测”移到左侧，“整体核对”移到右侧 |

## 数据

计算脚本新增 `--params '{"只保护":"<保护对象字段名>"}'`（需同时加 `--regrade`）：只把这一项当作保护对象重新做二次定级、整体核对与换模型复测，结果写入任务文件的“单独保护”下，不覆盖“保护全部”的结果。界面上的“点击计算”走同一条路径。

内置结果中已算好的单独保护：IEEE 30 节点算例的“机组报价”“节点相角”。
