# V6 变更记录

## 2026-10-14 · 按用户第三轮意见修改

- 保护对象选择条：“先选保护对象”改为“保护对象”。
- 单字段推断风险：
  - 单字段判定线统一为 0.7，不分接收方；指标“单独可过线的字段”、表中结论（“单独过线”/“单独不过线”）、竖线和右侧读数都按这条线，前后一致。多个字段合并时仍按接收方区分判定线（社会公众 0.7，其他 0.8）。
  - 推断精度条不再只用过线与否两种颜色，改为随数值由蓝到黄再到红逐渐加深。
  - 推断曲线的图例加底色和边框，悬停时突出对应曲线，并注明可点击。
- 聚合推断风险：
  - 总览图每个字段分为“单独作用（K = 0）”和“背景增益”两段，增益用红色斜纹；行距加大，K = 0 的部分更清楚。
  - K 滑块缩小，放到总览图右下角，旁边显示达到直接定级线的字段数。
  - 左表改为“单独作用 ＋ 背景增益 ＝ M”，增益为红色。
  - 右侧新增竖向玻璃选择器，单独切换 K；点选一行时默认与顶部的 K 一致。推断精度分成灰色的“只有背景”、按数值着色的“该字段单独作用”、红色的“背景增益”三段。
  - 字段名不再换行。
- 二次定级：
  - 整套等级方案移到页面上方。
  - 不再按保护对象拆分，默认展示“保护全部保护对象”的结果。
  - 新增“只保护某一项”：未计算为灰色，点击后在后台计算，算完可以切换查看；与“保护全部”的结果分别保存。
  - 当前选中的范围按钮内的标签改为白色，避免绿字落在蓝底上看不清。
- 定级效果：“整体核对”与“换模型复测”左右互换。
- 计算脚本：新增“只保护”参数；服务端把该参数传给计算脚本。
