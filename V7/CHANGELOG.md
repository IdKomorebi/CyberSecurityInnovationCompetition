# V7 变更记录

## 2026-10-14 · 按用户第四轮意见修改

- 问号提示：原来用样式在问号下方弹出，靠近右边缘时撑出滚动条，鼠标一动就消失又出现，来回抖动。改为一个固定在窗口上的浮层，位置限制在窗口内，靠近底部时显示在问号上方。
- 单字段推断风险（有公开基底的任务）：
  - 原来的单独推断精度包含公开基底。例如 PJM 的“发电总出力”，仅凭公开基底就有 0.974，于是 22 个字段都显示“单独过线”，与聚合推断页 K = 0 时很小的 M 对不上。
  - 现在精度条分成灰色的公开基底和彩色的字段自己的作用，数值后标出比公开基底提高多少。
  - 公开基底单独已过线时，结论改为“公开基底已过线”，不计入“单独可过线”，并在表上方说明原因。
  - 指标改为“比公开基底提高最多”和“仅凭公开基底”。
- 聚合推断风险：
  - 右侧竖向 K 选择器可以上下拖动，跟手移动，松开后吸附到最近的 K；点击仍可直接选择。
  - 单独作用和背景增益合成一段，加白色描边和随数值着色的微光；左表的条也同样处理。
  - 背景字段改为蓝色标签，前面加“背景字段”标题；有公开基底时另加“＋公开基底”。
  - 下方用浅色区块隔开，先列出含该字段的越线组合（同一组合合并接收方），再画所选组合的推断曲线：真实值（深色）、去掉该字段后的其余字段（青绿色）、整个组合（红色）。原来的“只有背景”曲线与真实值颜色太接近，已改。
  - 不在任何越线组合中的字段，仍显示最佳背景下的推断曲线。
- 二次定级：联合评估的原因写出“若保持原级，整套方案的综合效用为多少；调到现等级后为多少，提高多少”，并给出安全收益、可用性成本、聚合推断惩罚各自的变化；下方列出该字段取各个等级时的整套方案效用，低于直接定级要求的等级标灰。
- 定级效果：一览表中“公开基底可推出”的问号不再占位，各列数值对齐。
- 计算：二次定级导出各级效用；新增 `--curves` 导出越线组合曲线；全量重跑时保留参数不变的单独保护结果。四个任务已按新代码重跑，等级结果与 V6 相同。

## 2026-10-14 · 第四轮意见的补充调整

- 聚合推断页左表的条回退为 V6 的样式（不加描边和微光）；单字段页表格里的条也不加。描边和微光只留在右侧详情。
- 背景增益统一改为紫色斜纹（总览图、左表、右侧、图例、增益数字），与“单独作用”末端的红色拉开对比；字段本身很强、右端已是红色时，增益仍看得清。
- 右侧分段条：
  - 背景段做成凹进去的灰色，带一点微光；宽度够时在段内标出背景精度。
  - 字段段左端圆角改小，与背景之间留一道缝，描边和微光减弱。
  - 条下方加 0 至 1 的刻度，方便看出背景有多大。
- 导览重做：每页改为“本页回答 → 一图看懂 → 页面上有什么（带编号的页面示意）→ 怎么用（两三步）→ 术语（一句话，详细解释放在问号里）”，文字大幅减少。
  - 一图看懂：概览是“接收方拿到字段 → 推断保护对象 → 超过判定线即越线”；一次定级是四步流程、判定表查表示例和“等级决定谁能拿到”；单字段是过线与不过线的两条示例；聚合推断是“只有背景 / 单独作用 / 背景增益”的分段与 M 的组成；二次定级是三种调级方式和“风险—可用性”权衡示意图；定级效果是调级前后跨过判定线的对比。
- 修复：总体概览第 2 步卡片“单独超过 0.7 的字段数”沿用了旧算法，没有扣除公开基底已过线的情况（PJM 会显示 22 个）。现在与单字段页同一口径。
