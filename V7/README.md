# 系统 V7

在 V6 的基础上，按用户 10 月 14 日的第四轮意见改：问号提示不再抖动；有公开基底的任务在单字段页分开显示公开基底和字段自己的作用；聚合推断页右侧可拖动切换 K，并改为按越线组合画推断曲线；二次定级的原因栏写出效用差。

## 启动

```bash
python V7/scripts/serve.py 8787 <显卡编号>     # 浏览器打开 http://127.0.0.1:8787/frontend/
```

## 页面

| 页面 | 内容 |
|---|---|
| 任务管理、总体概览、1 一次定级 | 同 V6；问号提示改为浮层，始终留在窗口内 |
| 2 单字段推断风险 | 单字段判定线 0.7，不分接收方。有公开基底的任务：精度条分为灰色的公开基底和彩色的字段自己的作用，数值后标出比公开基底提高多少；公开基底单独已过线时，结论为“公开基底已过线”，不计入“单独可过线”，并在表上方说明 |
| 3 聚合推断风险 | 顶部总览同 V6。右侧：上下拖动玻璃块切换 K；背景字段用醒目的标签；单独作用和背景增益合成一段，带描边和微光；下方浅色区块列出含该字段的越线组合（同一组合对多个接收方越线时合并为一行），点选一个组合，画出真实值、去掉该字段后的其余字段、整个组合三条曲线 |
| 4 二次定级 | 同 V6；联合评估的原因写出“保持原级”与“现等级”时整套方案综合效用之差及构成；另列该字段取各个等级时的整套方案效用 |
| 5 定级效果 | 同 V6；一览表中的问号不再占位，各列数值对齐 |

## 数据

- 二次定级（`engine/grading/second.py`）为每个调高的字段导出“各级效用”：其他字段不动，只改这一个字段的等级时，整套方案的综合效用、构成和含该字段的越线组合数。
- 计算脚本新增 `--curves`：读取已生成的任务文件，为每个字段取含它的前 6 个越线组合，训练“组合”和“组合去掉该字段”两个模型，曲线写入 `samples/<任务>_组合曲线.json`，界面在打开聚合推断页时读取。
- 全量重跑（`--regrade`）时，参数不变的“只保护某一项”结果会保留。
