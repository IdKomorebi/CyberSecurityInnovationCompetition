# 系统 V5

在 V4 的页面结构上，按用户 10 月 14 日的第二轮意见改：整体换成浅色液态玻璃风格，重点信息加样式，单字段与聚合推断两页重做，二次定级与定级效果按保护对象组织。

## 启动

```bash
python V5/scripts/serve.py 8785 <显卡编号>     # 浏览器打开 http://127.0.0.1:8785/frontend/
```

## 页面

| 页面 | 内容 |
|---|---|
| 任务管理、总体概览 | 同 V4，换新样式 |
| 1 一次定级 | 上方四个步骤卡片可点击，弹窗分别展示规则库（条文、判定表、等级与共享范围）、大语言模型（检索方式、提示词要点、初判分布、示例）、人工复核（逐条对照）、一次等级分布；下方左表右依据 |
| 2 单字段推断风险 | 吸顶的保护对象选择条；左表为每个字段单独的推断精度；右侧为所选字段的读数与推断曲线 |
| 3 聚合推断风险 | 顶部是全部字段推断敏感度总览，用玻璃滑块调 K；左表为每个字段“单独 → 有背景时加入该字段”的推断精度与 M，可按“背景放大”“达到直接定级线”筛选；右侧逐级展示在哪些背景下作用被放大、推断曲线、含该字段的越线组合 |
| 4 二次定级 | 上半部分为与所选保护对象有关的调整；下半部分为整套等级方案（效用、训练、构成），注明由所有保护对象共同决定、切换保护对象时不变 |
| 5 定级效果 | 三张接收方卡片（划线为一次定级、大数字为二次定级、竖线为判定线）；全部保护对象一览；整体结论与台账导出；整体核对与换模型复测 |

每页“本页导览与参数”抽屉：本页回答的问题、流程示意、怎么读这一页、术语卡片、与本页有关的参数。

## 数据

计算脚本在 V4 基础上为每项保护对象导出全部候选字段的“背景明细”（各 K 下的最佳背景、只有背景的精度、背景加该字段的精度、M），供聚合推断页左表使用；推断曲线仍只为每项保护对象的若干字段导出。

## 后续工作（未开始）
