# 系统 V4

以 V1 的布局（铺满宽屏、深蓝侧栏）为底，吸收 V2/V3 的线条图标，按用户 10 月 14 日的意见重排页面。

## 启动

```bash
python V4/scripts/serve.py 8784 <显卡编号>     # 浏览器打开 http://127.0.0.1:8784/frontend/
```

没有深度学习库时自动进入演示方式（只读）。

## 页面顺序

| 页面 | 内容 |
|---|---|
| 任务管理 | 内置任务卡片、切换任务、新建任务入口 |
| 总体概览 | 五个步骤的结果、各接收方对保护对象的推断精度（一次 → 二次）、等级分布 |
| 1 一次定级 | 左侧字段定级结果大表；右侧为所选行的判定依据（模型初判、复核、判定表位置、国标条文），用行高亮、面板顶边与箭头标明对应关系 |
| 2 单字段推断风险 | 选保护对象；每个候选字段的等级、可获取的接收方、单独推断精度与结论；点击一行看推断值与真实值；下方为各接收方合并全部可获取字段的推断精度与曲线 |
| 3 聚合推断风险 | 选保护对象和字段；K = 0、1、2 时“只有背景”与“背景加该字段”的推断精度对比，得出字段推断敏感度 M；两条推断曲线对照；全部字段的 M 随 K 变化；聚合后越线的组合 |
| 4 二次定级 | 按保护对象查看字段调整明细与右侧依据；训练过程与综合效用构成 |
| 5 定级效果 | 调级前后各接收方的推断精度、整体核对、换模型复测、调级无法解决的项、导出台账 |

每页右上角“导览与参数”打开抽屉：“页面说明”介绍本页做什么；“参数调整”是与本页有关的参数，可应用并重跑。

## 与 V3 的数据差别

计算脚本在 V3 基础上增加了展示用曲线（`展示` 字段）：每个候选字段单独推断的曲线、各接收方合并全部字段的曲线、背景增益前后的曲线。推断精度缓存复用，未重新训练字段组合。
