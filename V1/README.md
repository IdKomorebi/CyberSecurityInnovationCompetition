# 系统 V1

## 查看（演示方式，不需要显卡）

```bash
python V1/scripts/serve.py 8780      # 然后在浏览器打开 http://127.0.0.1:8780/frontend/
```

远程服务器上运行时，在编辑器的“端口”面板里转发 8780。

## 页面

侧栏分组可展开、收起；顶部卡片显示当前任务，点击切换。

| 分组 | 页面 | 内容 |
|---|---|---|
| | 任务管理 | 内置任务卡片、切换任务、新建任务入口（演示方式下不可提交） |
| | 总体概览 | 指标、五步流程、各接收方对敏感数据的推断精度（一次 → 二次）、等级分布 |
| 规则与参数 | 等级与接收方 | 各等级的共享范围、各类接收方可获取的等级与字段数、判定表 |
| 规则与参数 | 判定参数 | 两条判定线、K、直接定级线；可修改并重跑 |
| 规则与参数 | 强化学习策略 | 效用函数的系数、严格模式、训练设置；可修改并重跑 |
| 定级 | 一次定级 | 字段定级结果大表，点击字段在行下展开判定依据 |
| 定级 | 推断风险 | 敏感数据 × 接收方的推断精度表、推断过程、最小越线组合 |
| 定级 | 字段敏感度 | 背景增益（拖动 K）、字段详情、敏感度矩阵 |
| 定级 | 二次定级 | 调整明细与依据、训练过程、综合效用的构成 |
| 效果 | 定级效果 | 调级前后的推断精度、剩余越线组合、换模型复测、导出台账 |

## 两种运行方式

- 演示方式：没有深度学习库时自动进入，只能查看内置结果，参数只读。
- 完整方式：`python V1/scripts/serve.py 8780 <显卡编号>`，参数页可以修改并重跑二次定级（复用 `runtime/cache/` 里缓存的推断精度）。

## 目录

- `frontend/`：界面。`index.html`、`app.css`、`app.js`；图表库在 `vendor/`，不连外网。
- `samples/`：四个内置任务的已算好结果（IEEE 30 节点、PJM、社区统计、医疗保险）。
- `scripts/serve.py`：服务，含状态与重跑接口。
- `scripts/build_samples.py`：重新生成一个任务（需要显卡）。`python V1/scripts/build_samples.py ieee30 --gpu 0`
- `scripts/rebuild_all.sh`：依次重新生成四个任务。
- `scripts/shots.py`：逐页截图并收集浏览器报错，输出到 `runtime/shots/`。
