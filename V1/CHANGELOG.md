# V1 变更记录

V1 是第一个成形的版本，下面按时间记录它是怎么改出来的。之后有大的改动时，复制为 V2 再改，V1 保持不动。

- 2026-10-12　两个小算例走通；界面第一版（四个页面，浅色）。
- 2026-10-13　接入 PJM、社区统计；加入整体核对、换模型复测；界面第二版（深色侧栏、卡片、标签页）。
- 2026-10-13　界面第三版：任务管理、规则与参数、定级四步、定级效果；撤掉共享审查与处置两页。
- 2026-10-13　二次定级的联合评估改为组相对策略优化，并求同一效用下的精确最优作参照；参数可改、可重跑。
- 2026-10-14　整体核对改为全部使用重新训练的推断精度：沿“逐个撤出”走完整条路径，取综合效用最高的位置；快速估计只用于给候选字段排序。

试过后弃用的做法（都留在工作记录里）：补越线组合再重新求解（收敛太慢）；把快速估计的整体推断精度直接放进效用函数（估计偏低，求解器专挑被低估的方案）；据重新训练结果反复修正估计再求解（更保守且不更安全）。
