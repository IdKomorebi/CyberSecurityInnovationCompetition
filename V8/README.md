# 系统 V8

在 V7 的基础上补齐后端：从网页上传一张数据表开始，后台自动完成全部步骤。PJM 任务去掉了“公开基底不能调级”的限制。

## 启动

```bash
python V8/scripts/serve.py 8788 [自动|处理器|显卡编号]     # 浏览器打开 http://127.0.0.1:8788/frontend/
```

- 需要 Python 3.10 及 numpy、pandas、scikit-learn、torch（有无显卡均可）；读取 Excel 需要 openpyxl。
- 没装 torch 时为演示方式：只能查看内置结果。
- 大模型密钥写在 `secrets/deepseek.env`，格式见 `secrets/deepseek.env.example`：
  - 一次定级与起草字段目录：`DEEPSEEK_*`；
  - 另一个大模型复核（可选）：`REVIEW_*`，可接任何兼容 OpenAI 接口的服务。本机配置的是阿里云百炼的 qwen3.8-max。
- 计算设备：默认“自动”，用 nvidia-smi 查每张卡的空闲显存，选空闲最多的一张；都不足 1.8 GB 或没有显卡时用处理器。

## 任务管理

任务卡片可拖动排序；鼠标移到卡片上可删除，文件移到 `runtime/回收站/`，可恢复。新建中的任务也显示为卡片，点开看进度。

## 新建任务（任务管理 → 新建任务）

1. **上传表格**：CSV 或 Excel，第一行为列名，每行一条记录。后端逐列判断数值、类别、时间、文本，并统计缺失值和示例值。
2. **确认字段目录**：大模型根据列名和示例值起草中文名、说明、类别、公开情况，并建议哪些列是保护对象；用户逐行修改后确认。在这一步还要选：
   - 是否按时间顺序排列；
   - 复核方式：人工，或另一个大模型；
   - 计算设备：自动或处理器。
3. **后台全流程**：一次定级 → 复核 → 推断验证 → 二次定级 → 整体核对与换模型复测 → 推断曲线。界面显示每一步的进度和日志，关掉窗口后台照常运行。

没配大模型密钥时，第 2 步退回为手工填写字段目录；一次定级需要大模型，会给出明确提示。

## 复核

一次定级页点“人工复核 → 详情”：逐条列出大模型初判、复核结果、理由和来源（人工或某个大模型）。

- 点“请另一个大模型复核”，由另配的模型逐条给出意见，单独成列，可逐条或全部采纳；
- 点“修改复核”可以改影响对象和影响程度，等级按判定表即时更新；
- 保存后自动重做二次定级及之后的步骤。

内置任务的复核意见保存在本版本的 `runtime/复核/`，不改动各版本共用的 `data/catalog/`。

## 接口

见 `scripts/serve.py` 文件头。主要有：

| 接口 | 作用 |
|---|---|
| `/api/status` | 状态、任务列表、当前作业 |
| `/api/upload` | 上传表格与画像 |
| `/api/draft` | 起草字段目录 |
| `/api/start` | 确认目录后开跑 |
| `/api/fix` | 保存复核并重算 |
| `/api/rerun` | 改参数重跑 |
