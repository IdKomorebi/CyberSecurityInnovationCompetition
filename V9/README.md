# 系统 V9

在 V8 的基础上，按“字段本身 → 聚合推断风险 → 定级与效果”重新组织页面，新增“越线组合”页，可在界面上选择组合最大字段数，更大的组合由估计器当场计算；新增澳大利亚 NEM 2024 内置任务作为主案例。变更见 [CHANGELOG.md](CHANGELOG.md)。

## 启动

```bash
python V9/scripts/serve.py 8788 [自动|处理器|显卡编号]     # 浏览器打开 http://127.0.0.1:8788/frontend/
```

依赖、大模型配置、新建任务、复核与接口同 V8，见 [V8/README.md](../V8/README.md)。

## 页面

| 分组 | 页面 | 回答的问题 |
|---|---|---|
| 字段本身 | 一次定级 | 字段泄露后影响多大，按国标该定几级 |
|  | 单独推断 | 只拿到这一个字段，能推出多少 |
| 聚合推断风险 | 考虑背景知识的字段推断风险 | 接收方已有其他字段时，再拿到它最多多推出多少（M = 单独推断 + 背景增益；背景预算 K 自动在 2、3 中选定） |
|  | 越线组合 | 哪些字段凑齐就越线、少一个就不越线；组合最大字段数可选，更大的组合当场估计 |
| 定级与效果 | 二次定级 | 强化学习根据 M 与越线组合学出整套等级 |
|  | 定级效果 | 调级后各接收方还能推出多少 |

## 越线组合的当场估计

```bash
python V9/scripts/combos.py <任务> --target <保护对象字段> --k <最大规模> [--gpu 自动]
```

结果缓存在 runtime/cache/<任务>_组合_<保护对象>_k<k>.json。实测：PJM 实际网损 k=4 用时 28 秒，找到 1 个 4 字段越线组合（估计 0.708，重新训练核对 0.729）；NEM PPCCGT k=4 用时 24 秒，没有新的越线组合。
