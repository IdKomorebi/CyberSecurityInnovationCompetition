# V9 变更记录

## 2026-10-18 · 估计器换为闭式读出估计器；侧栏固定；K 选择器可拖动

- **核对**：原系统的组合估计用的是门控网络的直接输出（早期方案），不是 GNN_Aggresvation 125 号定稿的估计器（重建预训练主干 ⊕ 随机主干、逐集合闭式岭读出、3 种子平均、三道数值防护，记为 C3）。
- **隔离实验**（社区统计 3808 个组合、NEM 与 PJM 各 1200 个组合，真值为逐个重新训练）：
  | 方案 | 平均误差（社区 / NEM / PJM） | 越线召回 0.7（社区 / NEM / PJM） | 单组合耗时 |
  |---|---|---|---|
  | 门控网络直接输出（原） | 0.056 / 0.039 / 0.054，整体偏低 | 0.78 / 0.77 / 0.98 | 0.06–0.08 ms |
  | C3（125 号定稿） | 0.0077 / 0.0084 / 0.021 | 0.99 / 1.00 / 1.00 | 213–342 ms |
  | **重建主干 ×1 + 全局预选 λ（采用）** | **0.0070 / 0.0048 / 0.013** | **0.99 / 1.00 / 1.00** | **0.27–0.64 ms** |
  | 重建 ⊕ 随机 ×1 + 全局预选 λ | 0.0066 / 0.0044 / 0.013 | 同上 | 0.53–0.95 ms |
  | 重建 ⊕ 随机 ×1 + 逐组合留出选 λ | 0.0080 / 0.0069 / 0.018 | 0.98 / 1.00 / 0.99 | 8–19 ms |
  另试对原估计器做单调校准，社区统计误差 0.059 → 0.031，仍明显不如闭式读出。
- **采用**：新增 engine/infer/readout.py（闭式读出估计器）与 scripts/estimators.py（门控网络、闭式读出估计器的训练与缓存）。门控网络只负责字段作用强度与诱饵门槛；组合估计（字段较多时的筛选、越线组合页的当场估计、整体核对的候选排序）全部改用闭式读出估计器。大数据集按行数与特征维度自动确定每批组合数。
- **重算**：社区统计完整重算（筛选依赖估计器）；其余任务重做二次定级（整体核对的候选排序依赖估计器）。
- **界面**：侧栏改为固定定位，页面滚动时不动；字段推断风险页的 K 选择器改为可拖动的液态玻璃块（拖动跟手、松开吸附，点击也可切换）；估计器的说明文字更新。

## 2026-10-17 · 背景预算 K 自动选定（2 或 3）

- **选定规则**（scripts/build_samples.py 的 choose_K）：取每个保护对象 M（K = 2）最大的 10 个字段。
  - K 从 1 到 2 时它们的 M 平均增加不到 0.01：已饱和，取 K = 2，不再计算；
  - 否则试算 K = 3：字段不超过 8 个时直接精确计算；更多时在每个字段 K = 2 的最危险背景上逐个加入一个候选字段（M 最大的 20 个），重新训练这些组合（结果写入推断缓存，重跑时不再训练）；
  - K = 3 时平均再增加不少于 0.01，或有字段再增加不少于 0.05，取 K = 3，否则取 K = 2。
  - 参数中 K 可选“自动”（默认）或固定值；“只保护某一项”沿用整体结果选定的 K。
- **结果**：NEM 选定 K = 3（新南威尔士可用发电容量对 TUMUT3 的 M 由 0.164 增至 0.269）；新增 5 个对 PPCCGT、1 个对 BW01 的 4 字段越线组合，二次定级后全部拆开（14 → 0），调高字段 16 → 17。其余内置与上传任务都选定 K = 2，结果不变。
- **界面**：
  - 背景知识下的单字段风险页新增“背景预算 K 的选定”卡片：K = 0…3 时风险靠前字段的平均 M 与增量、选定依据、增加最多的字段及其背景；K 滑块默认停在选定值，刻度下有紫点标记。
  - 越线组合页的“组合最大字段数”默认取 K + 1，按钮上标“K + 1”；估计器结果与已重新训练的组合去重。
  - 二次定级页两路输入标出所用 K 与越线组合的最大规模。
  - 参数抽屉中 K 改为下拉：自动（2 或 3）或固定值。
- **计算**：engine/grading/second.py 的 sensitivity 改为只遍历已核对的组合，结果与原实现逐项一致，K = 3 时字段多也能很快算完。

## 2026-10-17 · 按“字段本身 → 聚合推断风险 → 定级与效果”重排

- **叙述主线**：页面分三组，与作品题目照应。
  - 字段本身：一次定级、单独推断；
  - 聚合推断风险：考虑背景知识的单字段风险、越线组合（新页）；
  - 定级与效果：二次定级、定级效果。
- **术语**：“字段推断敏感度”改名为“字段推断风险 M”，即单独推断加背景增益。
- **新页“越线组合”**：
  - 列出所选保护对象的全部最小越线组合，标明能凑齐的接收方、推断精度、来源和二次定级后是否仍成立；
  - 右侧画“单独、两两……逐层凑齐”的子集格子图，列出组合成员的单独推断与 M，并给出推断曲线；
  - 另有字段在越线组合中出现次数的统计。
  - “组合最大字段数”可选 2 至 6（默认值后改为 K + 1，见上）。规模不超过推断验证精确计算范围的组合直接用重新训练的结果；更大的规模由估计器当场计算（scripts/combos.py）：对圈定字段的全部组合打分，单调闭包后找出最小越线组合，再对估计值最高的 20 个重新训练核对。估计器每个任务训练一次并缓存。
- **背景知识下的单字段风险页**：去掉越线组合，改为“与哪些字段一起开放最危险”，列出各 K 下的见证背景，并给出最危险背景下的推断曲线。
- **二次定级页**：顶部新增“两路输入”栏，说明字段推断风险 M 进入直接定级与安全收益、越线组合进入聚合推断惩罚，由强化学习学出整套等级；点击可跳到对应页面。
- **新增内置任务**：澳大利亚国家电力市场（NEM 2024）。30 个公开字段、3 台机组出力作为保护对象。南澳风电出力预测单独推断燃气机组 PPCCGT 出力 0.183，加上南澳可用容量与光伏预测后为 0.811，三项构成最小越线组合；8 个越线组合经二次定级全部拆开。
- **计算脚本**：各任务的数据读取抽成 scripts/taskdata.py；生成任务文件后自动补充越线组合的子集精度（scripts/lattice.py）。
- 服务端新增 /api/combos（发起与读取当场估计）；任务顺序中 NEM 排第一。
