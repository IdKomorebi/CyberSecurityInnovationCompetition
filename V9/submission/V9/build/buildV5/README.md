## 主要修改

报告保留原有章节结构与测试证据，减少主线中打断阅读的实现细节。将单独推断、字段推断风险 M、越线组合及二次定级之间的关系写得更清楚，并处理 buildV4 留待确认的三处理论表述问题。

讲稿明确：字段的 M 达到 0.7，直接定为与对应保护对象同级；其他字段结合组合风险与数据使用价值，由效用函数统一权衡。视频沿用龙安灵心 v3.1 音色重新配音和连续录屏，较上一版降低约 7% 语速，时长约 5 分 14 秒。

## 维护与复现

`scripts/` 保存报告修订、原理图、报告排版、展示材料和打包脚本；`video/scripts/` 保存 TTS、音频时间轴、连续录屏及视频合成脚本。所有修改均位于 buildV5，旧版本保留。

`package/` 是提交程序包的来源；`video/work/` 是本次录制工作目录，两者用途不同。提交时选择 `deliverables/` 内的文件即可。
