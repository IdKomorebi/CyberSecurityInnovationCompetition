## 原理图

| 图号 | 文件 | 绘制方式 |
|---|---|---|
| 2-5 | `fig_batch` | 遮挡矩阵、独立网络、堆叠参数与独立梯度 |
| 2-6 | `fig_gate` | 列打乱、门控连线、作用强度与数值轴上的诱饵门槛 |
| 2-7 | `fig_readout` | 预测与重建双目标、冻结的共享主干、逐组合独立读出 |
| 2-10 | `fig_grpo3` | 等级概率、整套方案矩阵、组内比较与策略更新循环 |

SVG 为原生矢量元素与可编辑文字，未嵌入位图。中文字体优先使用 Noto Sans CJK SC，回退为微软雅黑、苹方；数学符号优先使用 DejaVu Sans。`img/` 同时提供这五张图的 PNG 和报告使用的 JPEG。示意强度、概率与路径曲线均已标明示意性质。

## 讲稿修改

- 开场改为“训练好的神经网络推断模型的准确率”，设定 0.7 为阈值。
- M 从“只拿到一个字段”过渡到“已有背景后再获得该字段的最大增量”，用 0.22 → 0.81、M = 0.59 说明；再解释无背景也参与比较，所以本案例的 M 不低于单独推断能力。
- 从字段协同产生的风险，过渡到接收方实际能凑齐的越线组合。
- 二次定级统一介绍等级下限、效用函数的三项权衡、强化学习的组内比较及结果。
- 核对了数字与界面展示口径：13 是 PPCCGT 的已重训组合数，14 是三台机组合计数；默认越线组合页还包含估计结果，录制说明已明确区分。效果页采用两类模型复测中的较高结果。

## 保留与核对

Word 文件内部仅 5 个图片文件发生变化，其余内容逐字节一致。PDF 全部文字及其位置保持一致；100 个未替换图片的页面逐像素一致，另 5 页在替换图范围之外逐像素一致。8 张页面截图、公式图片、其他原理图和测试图均保持原文件内容。没有重新排版或改动图注。

程序继续使用 `../buildV3/package/数据定级与共享审查系统/`。本版不重复打包程序，不改系统代码和缓存。原有 V9 源文件及 buildV3 文件未覆盖。

## 重建

在本目录执行（需要 CairoSVG、Pillow、PyMuPDF，以及 Noto CJK 和 DejaVu 字体）：

```bash
python scripts/draw_principles.py
python scripts/build_v4.py
```

本机可使用 `/data1/duhaocun/miniconda3/envs/Pytorch310_codex/bin/python`。重建脚本直接替换 buildV3 的 Word 媒体文件和 PDF 图像对象，以保持原排版；报告 Markdown 从上层 V9 的原文复制，仅转换图片路径。
