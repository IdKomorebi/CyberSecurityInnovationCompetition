## 2.4 推断精度的测量

推断精度 V(S) 是全文度量风险的统一工具：字段推断风险、越线组合、整体核对都建立在它之上。按 2.2.3 节的定义，V(S) 是接收方只使用组合 S 中的字段时，对保护对象所能达到的最好估计效果。测量 V(S) 的直接做法是针对每个组合单独训练一个推断模型，再在留出数据上计算决定系数。本节说明如何在组合数量很大时完成这一测量，原理如图 2-4 所示。

![图 2-4 推断验证与字段推断风险](figures/fig_infer.png)

### 2.4.1 遮挡输入的成批训练

**问题。** 30 个候选字段中不超过 3 个字段的组合有 4525 个，每个组合都要训练一个模型并用 3 个随机种子取平均，逐个训练的时间无法接受。

**原理。** 训练一个只看组合 S 的模型，等价于训练一个输入为 x ⊙ m_S 的模型，其中 m_S ∈ {0,1}^d 是遮挡向量，S 中字段对应的输入列为 1，其余为 0。组合 S 的网络第一层为

$$h_S^{(1)} = \mathrm{ReLU}\left((x \odot m_S)\, W_S^{(1)} + b_S^{(1)}\right)$$

被遮住的列恒为 0，对应的权重不接收梯度，网络因此看不到组合以外的字段，后续层与普通全连接网络相同（两层隐藏层，宽 64 和 32）。不同组合的网络结构相同、参数互不共享，可以把一批组合 𝒮 的参数沿新增的一维堆成张量，用一次批量矩阵乘法同时完成全部组合的前向与反向计算，损失为各组合损失之和：

$$\mathcal{L} = \sum_{S \in \mathcal{S}} \frac{1}{|D_{\mathrm{tr}}|} \sum_{t \in D_{\mathrm{tr}}} \left\Vert f_S(x_t \odot m_S) - y_t \right\Vert^2$$

由于各组合的参数没有耦合，总损失对某一组合参数的梯度只来自该组合自身的损失项，成批训练与逐个训练在数学上等价，只是把大量小规模计算合并成少量大规模计算，充分利用显卡的并行能力。一张显卡上可以同时训练数百至上千个组合。

**设置。** 数据按 8∶2 划分训练与留出，训练 80 轮；保护对象有多个分量时取各分量 V 的平均，类别型保护对象做独热编码；每个组合用 3 个随机种子训练取平均，最后按 2.2.3 节做单调闭包。

### 2.4.2 快速估计网络

**问题。** 社区统计数据有 95 个候选字段，不超过 3 个字段的组合有十四万余个，即使成批训练也难以全部完成。此时需要一种对任意组合都能快速给出近似推断精度的方法，用来筛选值得重新训练的组合。

**条件预测器原理。** 训练一个同时接收遮挡后的输入 x ⊙ m 和遮挡向量 m 的网络 g(x ⊙ m, m)。训练时对每个样本随机抽取遮挡向量，以均方误差为损失。若遮挡分布对每个组合 S 都赋予正的概率、网络容量足够，则最小化期望损失

$$\min_g\ \mathbb{E}_{m}\ \mathbb{E}_{(x,y)}\left[\left(y - g(x \odot m, m)\right)^2\right]$$

的解满足 g(x ⊙ m_S, m_S) = 𝔼[y | x_S]，即对每个组合都给出该组合下的最优预测。于是一个网络训练一次，就近似得到了所有组合的推断模型，组合 S 的估计精度只需把 m_S 输入网络、在留出数据上计算一次决定系数。遮挡比例按 q = 0.02 + 0.95u³（u 为均匀随机数）抽取，使多数样本只保留少数几个字段，与待查询组合的规模（不超过 3 至 6）相匹配。

**分解式门控与字段作用强度。** 网络第一层中字段 i 的权重写成分解形式

$$z = (x \odot m)\left(\Omega \odot \left(\prod_{l=1}^{D-1} \gamma^{(l)}\right) \mathbf{1}^{\top}\right) + W_m m$$

其中 Ωᵢ 为字段 i 的权重行，γᵢ⁽ˡ⁾ 为 D − 1 个标量门控。对 Ω 和各 γ 施加普通的平方惩罚。在分解式参数化下，这一平方惩罚等价于对每个字段的整行权重施加 2/D 次的组稀疏惩罚[23]：门控的乘积为某个字段整体缩放，惩罚促使与保护对象无关的字段整体收缩到 0。训练完成后，字段 i 的作用强度取 rᵢ = |∏ₗ γᵢ⁽ˡ⁾| · ‖Ωᵢ‖。

**诱饵字段与无关门槛。** 作用强度只给出排序，还需要判断多大的强度才算有作用。系统在输入中混入 30 个诱饵字段，每个诱饵是某个真实字段按行随机打乱后的副本：边缘分布与真实字段相同，但与保护对象没有关系。诱饵字段的作用强度构成无关字段的经验分布，取其 90% 分位数作为门槛，强度不高于门槛的真实字段视为无关。

**使用方式。** 快速估计网络只用于排序和筛选：它的一个网络要兼顾所有组合，估计值整体偏低（社区统计上平均偏低约 0.05，3.7.4 节），因此筛选时在判定线以下留出余量，入选组合一律重新训练，用于定级的推断精度均来自重新训练。

### 2.4.3 推断验证流程

候选字段不超过 8 个时，成批训练全部组合；更多时训练不超过 3 个字段的全部组合，选定 K = 3 时另行训练试算所需的 4 字段组合（2.5.1 节）。字段多到无法训练全部 3 字段组合时，按算法 1 先估计、再重新训练。算法中第 4 步取判定线下 0.15 的余量，用于抵消估计的偏低；第 5 步把入选组合的全部子集一并重新训练，保证最小越线组合的判定（去掉任一字段即不越线）有可靠的子集数值；随机抽取的 400 个组合用于检验筛选是否漏掉了实际越线的组合。

```
算法 1　推断验证（字段较多时）
输入：候选字段 H，保护对象 y，判定线 θ，组合规模上限 k
输出：已核对组合的推断精度表 V
1　训练快速估计网络 g，得到字段作用强度 r 与诱饵门槛 τ
2　H′ ← { i ∈ H : rᵢ > τ }，按 r 从大到小取前 45 个
3　对 H′ 中全部 |S| ≤ k 的组合计算估计值 Ṽ(S)
4　C ← { S : max Ṽ(S) ≥ θ − 0.15 } 中估计值最大的 2500 个
5　C ← C ∪ 全部单字段 ∪ C 中组合的全部子集 ∪ 随机抽取的 400 个组合
6　对 C 中组合成批重新训练（3 个随机种子），得到 V(S)
7　对 V 做单调闭包；统计随机抽查中估计未越线而实际越线的个数
```

更大规模的组合有两种处理方式：在界面上调大组合最大字段数，按算法 2 当场估计并按需重新训练（2.5.2 节）；定级完成后，由整体核对对接收方可获取的全部字段统一检查（2.6.4 节）。
