# CyberSecurityInnovationCompetition

“华为杯”第五届中国研究生网络安全创新大赛 · 创意作品赛的参赛项目。

队名“数据安全组”，4 人。

作品方向：面向聚合推断威胁的数据定级与共享审查系统。用同一套推断验证算法做两件事：定级时把“多个字段合起来能推出什么”算进等级；对外提供数据时，对因此被调高等级的字段给出处置办法。

## 当前状态

2026-10-11：完成资料收集和总体方案第二稿（已按答复修改）；非电力数据集粗查通过（[记录](experiments/00_非电力数据集粗查/结果.md)）。系统和报告还没有开始。

2026-10-12（续）：DeepSeek 的 46 条初判已逐条复核，7 条按复核意见调整并留痕（`data/catalog/*_复核.json`）。二次定级模块和新界面的四个页面已能运行，两个小算例全流程走通，查看方法见 [system/README.md](system/README.md)。

## 目录

现在有 `docs/`、`reference/` 和 `experiments/`。其余目录等有内容时再建，计划中的完整结构见总体方案第十节：

```text
docs/          方案与设计文档
reference/     外来的只读材料
engine/        算法
system/        可运行的系统（backend、frontend、samples、scripts）
data/          数据整理脚本和规则库
experiments/   测试报告用到的实验
submission/    参赛材料（report、video、package、final）
logs/          工作记录
```

## 与其他项目的关系

- `../diantan`：电碳比赛的作品。本项目沿用其后端框架和大部分算法（公式关系识别、稀疏门控、处置评估、核验），按新主题重新安放，前端重做。对照表见总体方案第四节。
- `../GNN_Aggresvation`：字段推断敏感度的研究和分类分级的实验。本项目只读取其中的方法和已有结果，不改动那边的任何文件。
- 南方电网的内部文件不进入本项目。规则依据只用公开的国家标准和行业标准。
