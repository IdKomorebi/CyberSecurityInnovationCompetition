# CyberSecurityInnovationCompetition

“华为杯”第五届中国研究生网络安全创新大赛 · 创意作品赛的参赛项目。

队名“我是华为轻薄本”，队长杜浩存，4 人。

作品方向：面向聚合推断威胁的数据定级与共享审查系统。给数据定级时，先验证各类接收方把能拿到的字段合起来能把无权获取的数据推到多准，再用强化学习把这种聚合推断计入等级，并给出每次调级的依据和调级前后的风险对比。

## 目录

```text
V1…V9/         系统各版本（当前为 V9）：界面 frontend/、脚本 scripts/、内置任务结果 samples/、说明与变更记录
engine/        算法（各版本共用）：一次定级、二次定级与强化学习、推断模型与快速估计、换模型复测
data/          规则库、字段目录与一次定级结果、原始数据（各版本共用）
experiments/   编号的实验，一个编号一个文件夹
docs/          方案与赛事要求
logs/          工作记录，按日期
reference/     官方文件、公开标准
secrets/       密钥，不入库、不进提交包
```

系统按版本号建目录（V1、V2……）。有大的改动时把上一版整目录复制为新版本再改，旧版本保持可运行，方便并排对比；小修改在当前版本内进行并记入该版本的 CHANGELOG.md。`runtime/` 是各版本自己的运行产物（缓存、日志、截图），不入库。
